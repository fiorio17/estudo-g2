# Estudo G2 — Inteligência Artificial

Revisão para a G2, montada a partir dos slides das aulas 11, 12, PLN II e 15.
Páginas HTML sem dependência externa; abrem direto no navegador, inclusive offline.

| Página | Conteúdo |
|---|---|
| `genetico.html` | Aula 11: ciclo do AG, fitness, seleção, crossover, mutação, TSP. Labs: simulação x² (4 bits), AG no caixeiro viajante, PMX/OX, mutações, força bruta. |
| `pln.html` | Aulas 12 e PLN II: pipeline, stopwords, stemming × lematização, BoW, TF-IDF, embeddings, cosseno, Word2Vec, Transformers, atenção, LLMs, RAG. |
| `visao.html` | Aula 15: pixels, RGB/BGR, cinza, Canny, HSV, máscaras, centro por momentos, jogo com webcam. |
| `simulado.html` | 73 objetivas e 4 discursivas, com correção imediata. |

Onde os slides trazem números ilustrativos ou deslizes, as páginas avisam (ex.: rótulos
de saltos no grafo do AG, 9! = 362 880, pesos de atenção ilustrativos). PMX e OX foram
conferidos contra os exemplos dos slides.

Bibliografia: Russell & Norvig, *Inteligência Artificial: Uma Abordagem Moderna*, GEN LTC, 2022.
